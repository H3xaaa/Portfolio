About

Hi, I'm Jonard Avenido, a game developer and graphic designer with a passion for building complete, polished experiences.

I don't just work on the visuals. I architect the systems too, from Firebase databases and user authentication to stats tracking and leaderboards. I've shipped real games and seen them through from concept to code.

The program focused on Graphic Design, Game Development, UI/UX, and backend systems, and many of the projects shown here were completed during that time.

I Shoot Hue

Unity C# Firebase Mobile

A color-based mobile shooting game where players identify and shoot hues against the clock. I built the full backend, Firebase auth, real-time database, player stats, and leaderboards, plus designed the S2W team logo and game UI.

Download game Watch trailer
System architecture, Player → Mobile App → Unity Engine → Firebase Database → Admin Panel & Analytics
Developer contribution

Built core UI screens for the game, including login and authentication flow, shop experiences, level selection, and leaderboard screens. I connected these interfaces with game systems so the player experience felt polished and coherent.

Gameplay features
  • Level timer and countdown that pushes the player to finish fast.
  • Coins and score tracking shown clearly in the HUD.
  • Target list showing blobs to hit and required color matches.
  • Color tagger mechanic for blobs: hit red, blue, or yellow targets with the correct paint button.
  • 3 lives shown as bucket icons to indicate remaining chances.
